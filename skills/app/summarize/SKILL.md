# summarize

## Procedure

1. Read the whole input before writing a word. A summary written while reading
   over-weights the beginning.
2. Extract three things, in this order:
   - **decisions** — what was settled, and by whom
   - **facts** — numbers, names, dates, versions
   - **open** — what was raised and not resolved
3. Preserve every number and identifier exactly. A summary that rounds a version
   number or a figure is worse than no summary.
4. Target one tenth the length. If the input has no decisions and no facts, say
   so instead of padding.
5. Never introduce a claim the source does not make, including "therefore".
